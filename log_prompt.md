# LOG PROMPT GENAI

## 1. Tujuan Penggunaan GenAI

GenAI digunakan sebagai alat bantu selama pengerjaan Tugas 2 IPSD, terutama untuk memahami instruksi praktikum, mempelajari kode program, membantu menyusun laporan, dan memahami hasil pengujian model CNN.

## 2. Catatan Penggunaan Prompt

| No. | Tujuan | Prompt yang Digunakan |
|---|---|---|
| 1 | Memahami tugas | Jelaskan instruksi tugas klasifikasi lesi kulit Mpox menggunakan Simple CNN. |
| 2 | Memahami kode | Jelaskan fungsi kode program pada setiap file sesuai modul praktikum. |
| 3 | Memahami proses CNN | Jelaskan proses training, testing, dan penggunaan 5 fold dengan bahasa sederhana. |
| 4 | Menyusun laporan | Bantu susun laporan praktikum klasifikasi lesi kulit Mpox dalam format README.md. |
| 5 | Menganalisis hasil | Bantu membandingkan hasil pengujian model dengan augmentasi dan tanpa augmentasi berdasarkan CSV. |
| 6 | Memahami evaluasi | Bantu menjelaskan confusion matrix, accuracy, precision, recall, F1-score, dan ROC-AUC. |

## 3. Peran GenAI dalam Pengerjaan

GenAI digunakan sebagai pendamping untuk membantu memahami materi dan menyusun penjelasan. Kode program, proses pelatihan, pengujian, serta hasil evaluasi tetap diperiksa berdasarkan modul praktikum dan hasil eksperimen yang diperoleh.

## 4. Verifikasi Hasil

Informasi dan penjelasan yang diperoleh dari GenAI diperiksa kembali dengan membandingkannya terhadap modul praktikum, kode program, serta hasil pengujian model.
